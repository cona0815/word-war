## 命中規則與多人準備

`spell-flight.js` 將施法者、技能、目標 ID、生命判斷與命中回呼分開。目標點依角色自身邊界與 anchor 換算，每格重新取得目標位置，避免固定打畫面中心。飛行抵達後才發出命中事件，由呼叫者扣血；不在蓄力或飛行中扣血。

目前預覽小招扣 10、大招扣 25，僅為動畫示範數值。八人排列為左側兩列四排，各自獨立 HP 與命中點；可傳入多個目標，同一次施法僅對每個唯一 ID 命中一次。暫停凍結角色／特效時間，重置取消舊攻擊。死亡或移除的目標不再受擊。

後續多人功能應另開模式，維持八景單人主線。連線時由伺服器決定攻擊 ID、有效目標、範圍判定、傷害與生死；客戶端僅播放伺服器確認的結果。正式技能需定義單體／範圍、預警、命中半徑、鎖定策略、取消條件與八人遮擋排列。此版有八目標本機測試，**尚無多人連線、正式範圍規則，亦未替換主線或天梯 Boss**。
