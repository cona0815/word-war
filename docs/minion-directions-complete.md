# 小兵四向素材補齊（2026-10-03）

## 範圍

補齊目前八景與大橋堂內建題庫所使用的全部 42 個小兵圖源。共 39 個造型家族、156 張透明 256×256 PNG：前次四個家族保留，本次新增 35 個家族、140 張。

- 同一星星造型的 digit 3 / letter E 共用方向圖。
- 同一石像造型的 digit 4 / letter G 共用方向圖。
- 原通用 pixel-enemy 使用既有皇冠史萊姆四方向。
- 其他怪物各自保留原色、種類、服裝與主要配件，不再用史萊姆替代上下方怪物。

## 朝向規則

| 小兵位置 | 朝向主角 |
|---|---|
| 左方、左上、左下 | 右側身 |
| 右方、右上、右下 | 左側身 |
| 中央上方 | 正面向下 |
| 中央下方 | 背面向上 |

中央上下欄沿用距主角水平位置小於 8 個百分點的判定。圖源依原怪物家族選擇，文字與血條不翻轉；出怪鍵位、排隊、碰撞、課程及 Boss 不變。圖片解碼失敗顯示可解碼替代圖，題目保持可見。

## 製作與復查

原稿由內建 ImageGen 依現有圖片產生，每組四格依序為正面、背面、左側、右側，純洋紅背景。Generate2DSprite 執行去背、分格、共同尺度及腳底對齊；原稿與中間檔留在本機，正式發布只納入四張 PNG。原小兵檔案沒有覆寫。

審圖：`minion-raw-review-1.jpg` 至 `minion-raw-review-4.jpg`；切分後預覽為 `minion-final-review-1.jpg` 至 `minion-final-review-4.jpg`。

## 驗證要求

- `qa-minion-png.py`：156 張圖有透明背景、安全邊界、同一家族腳底一致。
- `qa-minion-coverage.mjs`：42 個實際圖源四方向、156 張 PNG 解碼與尺寸；缺圖時仍可顯示題目。
- `qa-minion-facing.mjs`：八位置實際渲染、文字未鏡射、無頁面錯誤。
- `qa-game.mjs` 與發布包檢查：保留既有玩法與確保素材進入 Git 發布包。

此範圍不包含未被目前題庫使用的備用字母怪物，也不增加行走動畫或八角度斜側身。未來新增怪物圖源須同時補入四向素材與覆蓋檢查。
